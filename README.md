## Status

**Pre-alpha.** Heavy development. Not ready for production use.

## Mission

EidosDB is a pure-Rust vector index: it receives precomputed embeddings plus
payloads and serves approximate nearest neighbor search, with no embedded
inference and no JVM. Built to be a sovereign, edge-deployable alternative to
US-only managed vector databases.
